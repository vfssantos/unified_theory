# 10. Chirality Mechanism

## Summary

This section explains how chirality emerges from geometry:

### 10.1 The Chirality Problem

- **Standard Model fact**: Only left-handed fermions feel weak force
- **Usual GUTs**: Put L and R in same multiplet, need mechanism to split
- **E₈ challenge**: Adjoint is real, naively gives L+R pairs

### 10.2 E₈'s Built-in Asymmetry

- **Key fact**: E₈ = Spin(16) adjoint + ONE half-spinor
  $$\mathbf{248} = \mathbf{120} \oplus \mathbf{128}$$
- **The 128**: Only one chirality of Spin(16) spinor
- **Consequence**: E₈ is intrinsically chiral at this level

### 10.3 Chirality from Projection

- **The window filter**:
  - Left-handed states: Internal coordinates near window center
  - Right-handed mirrors: Internal coordinates near window boundary
- **Selection rule effect**:
  - L states pass through window
  - Mirror L states (would-be R partners) excluded

### 10.4 Geometric Picture

- **Cube vertices (8_L)**: Deep inside acceptance window
- **Equator vertices (8_R)**: Also inside, but these ARE the right-handed singlets
- **Mirror states**: In opposite hemisphere (h < 0) or second 600-cell
- **Mass suppression**: Mirrors get large mass from boundary proximity

### 10.5 Formal Statement

**Proposition**: Under the Golden Slice projection with symmetric window W:
1. The 16 Weyl spinor of Spin(10) projects entirely into the h > 0 hemisphere
2. The conjugate 16̄ projects into h < 0
3. The window W includes h > 0 but attenuates h < 0
4. Result: Chiral spectrum in low-energy theory

- Show that window geometry separates chiralities
- Currently asserted, not proven
