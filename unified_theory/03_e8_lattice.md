## 3.1 Definition and Construction

### 3.1.1 Explicit Definition

> **Definition 3.1 (E₈ Lattice):**
> The E₈ lattice $\Lambda_{E_8}$ consists of all vectors $(x_1, x_2, \ldots, x_8) \in \mathbb{R}^8$ satisfying:
> $$\Lambda_{E_8} = \Big\{ \mathbf{x} \in \mathbb{R}^8 \;\Big|\; x_i \in \mathbb{Z} \text{ or } x_i \in \mathbb{Z}+\tfrac{1}{2}, \quad \sum_{i=1}^8 x_i \in 2\mathbb{Z} \Big\}$$

In plain language:
- Coordinates are either **all integers** or **all half-integers**
- Their sum must be **even**

### 3.1.2 Why This Definition?

The conditions ensure the lattice is:
- **Even**: $|\mathbf{x}|^2 \in 2\mathbb{Z}$ for all $\mathbf{x} \in \Lambda_{E_8}$
- **Self-dual**: $\Lambda_{E_8}^* = \Lambda_{E_8}$ (the dual lattice equals itself)
- **Unimodular**: The fundamental domain has volume 1

These properties make E₈ the **unique** even, self-dual lattice in 8 dimensions.

## 3.2 The Root System

The **roots** of E₈ are the minimal nonzero vectors, all having length $\sqrt{2}$.

### 3.2.1 Classification

The 240 roots decompose into two types:

**Type D₈ (112 roots):**
$$\{\pm e_i \pm e_j : 1 \leq i < j \leq 8\}$$
where $e_i$ is the $i$-th standard basis vector.
- Form: $(\pm 1, \pm 1, 0, 0, 0, 0, 0, 0)$ and permutations
- Count: $\binom{8}{2} \times 4 = 112$

**Type S₈ (128 roots):**
$$\left\{\frac{1}{2}(\pm 1, \pm 1, \ldots, \pm 1) : \text{even number of minus signs}\right\}$$
- Half-integer coordinates with even parity
- Count: $2^8/2 = 128$

**Total:** $112 + 128 = 240$ roots.

### 3.2.2 Verification

All roots have the same length:
- Type D₈: $|(\pm 1, \pm 1, 0, \ldots)|^2 = 1 + 1 = 2$ ✓
- Type S₈: $|\frac{1}{2}(\pm 1, \ldots, \pm 1)|^2 = 8 \times (1/2)^2 = 2$ ✓

$$s_\alpha(\mathbf{x}) = \mathbf{x} - 2\frac{\langle \mathbf{x}, \alpha \rangle}{|\alpha|^2}\alpha$$
