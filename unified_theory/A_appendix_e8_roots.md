# Appendix A: E₈ Root System

## Summary

Complete reference for E₈ lattice and roots:

### A.1 Lattice Definition

$$\Lambda_{E_8} = \{(x_1,...,x_8) \in \mathbb{R}^8 \mid x_i \in \mathbb{Z} \text{ or } x_i \in \mathbb{Z}+\tfrac{1}{2}, \sum x_i \in 2\mathbb{Z}\}$$

### A.2 The 240 Roots

**Type I (112 roots)**:
All permutations of (±1, ±1, 0, 0, 0, 0, 0, 0)

**Type II (128 roots)**:
All (±½, ±½, ±½, ±½, ±½, ±½, ±½, ±½) with even number of minus signs

### A.3 Simple Roots

- α₁ = (1, -1, 0, 0, 0, 0, 0, 0)
- α₂ = (0, 1, -1, 0, 0, 0, 0, 0)
- ...
- α₈ = (½, ½, ½, ½, ½, ½, ½, -½)
