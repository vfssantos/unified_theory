## 4. P/I/F RELATIONSHIP

Madison & Madison’s “unified theory” treats P, I, F icosahedral quasilattices as **Bravais-like types** in 6D:

* **P-type**:

  * Derived from the primitive 6D lattice Z⁶ (or an equivalent basis).
  * Projection window centered in the 6D hypercube gives a **triacontahedron with two node types A, B** at its vertices.

* **I-type (body-centered)**:

  * Add centering points at ½(1,1,1,1,1,1) etc.
  * Projection introduces **one additional node type C inside each zonohedron**.
  * So I-type quasilattice has nodes A, B, C.

* **F-type (face-centered)**:

  * Add more centering; the C-type nodes form clusters (icosidodecahedra or fragments) inside the zonohedra.
  * F-type contains **all P-type nodes as a subset**; I and F contain all P nodes plus extra C nodes.

So:

* **P/I/F are three different 6D centering schemes** (analogous to sc/bcc/fcc) that all project to 3D icosahedral tilings with Danzer-based cells.
* Node types **A, B, C are the same “three” across P/I/F**, but:

  * P uses mainly A,B;
  * I adds isolated C nodes;
  * F organizes C nodes into larger clusters (e.g. icosidodecahedral clusters).

In your language:

* P/I/F are three **ways of placing the same quasicrystal “grid”** in 6D,
* and A/B/C are **three flavors of vertex** that appear in those grids.
